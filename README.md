# DatabaseSynchronization
Синхронизация баз данных access, находящихся на разных пк.
## Условия
- Устройства должны быть подключены к одной сети.
- На одном из устройств должна иметься папка с общим доступом
- Таблицы должны содержать одинаковые столбцы
## Как создать папку с общим доступом
1. Нажмите правой кнопкой мыши на папку для синхронизации → Свойства.
2. Перейдите на вкладку Доступ → нажмите кнопку Расширенная настройка.
3. Поставьте галочку Открыть общий доступ к этой папке.
4. Нажмите кнопку Разрешения.
5. В списке выберите группу Все (или нажмите «Добавить», введите Все и нажмите ОК).
6. В нижнем окне поставьте галочки Чтение и Изменение (это разрешит создание и удаление файлов). Нажмите ОК.
7. Не закрывая окно свойств, перейдите на соседнюю вкладку Безопасность.
8. Нажмите кнопку Изменить → Добавить
9. В поле ввода напишите слово Все и нажмите «Проверить имена» (оно подчеркнется). Нажмите ОК.
10. Выделите группу Все в верхнем списке и в нижнем списке поставьте галочку Изменение (или «Полный доступ»). Нажмите ОК во всех окнах.
ВНИМАНИЕ: Используйте этот способ, если оба компьютера находятся в одной доверенной локальной сети (дома или в небольшом офисе)
## Возможности:
- Добавление записей
- Мягкое удаление записей (не удаляет физически, но помечает как удаленное)
- Изменение записи
### При конфликте изменений применяется то, которое произошло позже
